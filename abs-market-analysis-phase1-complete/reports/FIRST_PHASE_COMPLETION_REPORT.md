# ABS Coil 시장분석 시스템 1차 구축 결과보고서

**기준일:** 2026-09-20  
**1차 완료 기준 MASTER:** `data/global/global_market_monthly_v7.csv`  
**대시보드:** `dashboard/app.py`

## 1. 1차 과제 목적과 완료 범위
무료 공개자료를 기반으로 자동차 시장 흐름과 ABS/ESC/통합제동/BBW·EMB 기술 신호를 한 화면에서 비교할 수 있는 내부 분석 MVP를 구축했다. 1차에서는 시장을 끝없이 확대하기보다 데이터 수집·검증 원칙과 대시보드 분석 구조를 먼저 완성하는 것을 종료 기준으로 삼았다.

현재 글로벌 MASTER는 3,350행, 20개 국가, 5개 시장군으로 구성된다. 시장군은 선진시장 14개국, 중남미 3개국(칠레·멕시코·브라질), 중국, 인도, 기존 참고계열인 중앙아시아/CIS(카자흐스탄)다. MASTER V7 기준 중복키 0건, value NULL 0건이며 저장값은 모두 `ACTUAL / SOURCE_PUBLISHED`다. 단, 이는 각 계열이 확보된 관측기간 안의 상태이며 국가별 장기 시계열 완성도를 의미하지 않는다.

## 2. 데이터 사용 원칙
- 무료·공식 공개자료 우선. 유료 데이터셋은 1차 범위에서 사용하지 않는다.
- NULL은 0으로 채우지 않는다. 계열 결측률이 30%를 초과하면 시장군 합계 후보에서 제외한다.
- 추정값을 사용할 때는 ACTUAL과 분리하고 근거·산식·주석을 남긴다. 현재 V7 글로벌 MASTER에는 추정값이 없다.
- 등록, 판매, 생산, 수출은 정의가 다르므로 임의 합산하지 않는다. 국가별 등록/판매는 '수요 추세 비교축'으로 사용할 수 있지만 절대 시장규모 하나로 단순 합산하지 않는다.
- 차량범위가 다른 지표도 분리한다. 예: 인도 국내판매는 Passenger Vehicles, 생산은 PV+3W+2W+Quadricycle 총생산이다.
- 공식 월간자료에 당월과 누계가 함께 있으면 누계를 검산장치로 사용한다.
- 앞으로의 갱신은 전체 재수집이 아니라 `마지막 수집월 → 신규 월만 수집 → 검증 → MASTER 추가` 방식의 증분수집을 목표로 한다.

## 3. 자료수집 과정에서 겪은 문제와 해결 노하우
### 3.1 KIPRIS 특허 — 검색량은 많지만 관련성이 낮음
초기 키워드 검색은 ABS/ESC/통합제동/BBW·EMB 주변의 광범위 문서를 가져와 REVIEW가 과도하게 발생했다. 단순 키워드 양을 늘리는 방식 대신 **제목·초록 필드검색 + IPC 필터 + STRICT 분류**로 전환했다. 샘플 V2에서 97건 중 PASS 70건까지 개선됐고, 전체 수집에서는 RAW 240건 중 STRICT PASS 163건을 확보했다.

**배운 점:** 검색 결과가 많다는 것은 데이터 품질이 높다는 뜻이 아니다. 기술 데이터는 '검색 → 후보 → 엄격분류'의 2단계 이상으로 설계하고, 초기 샘플에서 PASS/REVIEW 비율을 먼저 확인한 뒤 전체수집으로 넘어간다.

### 3.2 글로벌 OECD — 최신월 국가수가 줄어드는 문제
국가별 발표시점이 달라 최신월을 단순 합산하면 선진시장 합계가 급락하는 것처럼 보였다. 이를 해결하기 위해 **월별 국가 커버리지 70% 이상일 때만 합계를 표시**하고, 비교용 고정 국가군을 별도로 관리했다.

**배운 점:** 다국가 월별 데이터에서 최신월의 숫자보다 '몇 개 국가가 포함됐는가'가 먼저다. 합계 차트에는 반드시 커버리지 게이트가 필요하다.

### 3.3 브라질 ANFAVEA — Excel 자동다운로드 실패
공식 사이트의 Excel/CSV 직접링크를 찾는 V4/V5 접근은 실패했다. 데이터를 임의로 만들지 않고 중단한 뒤, 공식 `Carta da ANFAVEA` PDF 수집으로 전환했다. 9개 PDF를 확보했고, 최초에는 전체 페이지에 `extract_tables()`를 적용해 매우 느려졌다. 이후 **최초 1회 PDF 구조분석 → 72개 표 CSV 저장 → 이후 단계는 CSV만 재사용**하는 방식으로 바꿨다. 생산·수출은 Total, 내수등록은 국산 Total+수입 Total을 사용하고 월/누계 구조를 확인한 뒤 MASTER에 병합했다.

**배운 점:** PDF는 매 단계 다시 읽지 않는다. ① 원본 보존 ② 최초 구조분석 ③ 필요한 표를 중간 CSV로 캐시 ④ 이후 검산·병합은 캐시만 사용한다. 자동다운로드 실패는 '데이터 부재'가 아니라 '접근 방식 실패'일 수 있다.

### 3.4 중국 CAAM — SSL 만료와 과도한 URL 탐색
CAAM 영문 사이트는 SSL 인증서 만료로 Python 요청이 실패했다. 공식 도메인에 한해서만 인증서 검증을 우회해 구조를 확인했다. 이후 상세페이지 ID를 수백 건 순차 탐색하는 방식은 지나치게 오래 걸려 사용자가 직접 중단했다. 해결책은 **실제 존재하는 공식 상세 URL을 먼저 선별 → 필요한 월만 패치 → 결측률 계산**이었다. 그 결과 2023 판매는 12/12개월, 생산은 9/12개월로 생산 NULL 25%를 달성해 30% 기준을 통과했다.

**배운 점:** 느린 수집이 시작되면 기다리기보다 `요청 횟수 × timeout`을 먼저 계산한다. 전체 ID 탐색보다 검색 인덱스/공식 목록에서 URL을 좁힌 뒤 필요한 월만 요청한다. SSL 문제와 데이터 파싱 문제도 분리해서 진단한다.

### 3.5 멕시코·인도 — 지표 정의를 억지로 통일하지 않음
멕시코는 생산·판매·수출을 서로 합산하지 않고 각각의 공식 월별 계열로 유지했다. 인도 SIAM 무료 보도자료에서는 국내판매와 생산의 차량범위가 다르다는 점을 발견해 scope를 별도로 저장했다.

**배운 점:** '글로벌 자동차시장'이라는 이름 때문에 서로 다른 원자료 정의를 강제로 하나의 지표로 만들면 오히려 분석 신뢰도가 떨어진다. 공통축은 방향 비교에 사용하고 원래 metric/scope는 반드시 보존한다.

## 4. 대시보드 변화 과정 — 대표 3단계
### 1단계: 시장 시계열 중심 초기안
초기 화면은 국내 생산·내수·수출과 연간 흐름을 한 화면에서 보여주는 데 집중했다. 기본적인 흐름 확인은 가능했지만 규모가 다른 계열을 같은 축에서 표시해 작은 변화가 묻혔고, 국내/해외 시장의 역할 구분이 약했다.

**개선 코멘트:** '데이터를 많이 보여주는 것'보다 '같은 축에 놓아도 되는 데이터인가'를 먼저 판단해야 한다.

### 2단계: 분석형 화면으로 개선
사용자 피드백에 따라 월간·연간 그래프의 스케일 문제를 재검토하고 국내/해외 구분을 복원했다. 특허에서도 ABS 같은 기존기술과 통합제동·BBW/EMB 같은 신기술의 절대 건수 차이 때문에 한 축에서 신기술이 거의 보이지 않는 문제가 확인됐다. 또한 빈 공간은 장식 대신 '질문 해석' 영역으로 활용하는 방향을 정했다.

**개선 코멘트:** 스케일 차이가 의미를 가릴 때는 축 분리 또는 패널 분리가 필요하다. 빈 공간은 사용자의 다음 판단을 돕는 기능에 우선 배정한다.

### 3단계: 1차 완료본
최종 1차본은 `국내 시장 / 글로벌 시장 / 기술·특허·질문 해석`의 3개 탭으로 정리했다. 글로벌 화면은 수요(등록·판매), 생산, 수출을 선택해서 보며 서로 다른 정의의 계열을 단순 합산하지 않는다. 특허 화면은 ABS·ESC와 통합제동·BBW/EMB를 좌·우 축으로 분리했다. 질문 해석은 자연어 답변 생성보다 먼저 사용자의 질문에서 시장/수요/생산/수출/특허/기술 키워드를 분석항목으로 연결하는 MVP로 제한했다.

**개선 코멘트:** 1차 MVP는 'AI가 답을 만들어내는 것'보다 어떤 데이터와 근거를 봐야 하는지 올바르게 연결하는 기능을 우선한다. 뉴스 자동수집과 근거문장 생성은 2차 과제로 분리한다.

> 코드 이력 참고: `dashboard/app_before_market_mvp.py`, `dashboard/app_before_timeseries.py`, 기존 `dashboard/app.py` 계열과 현재 1차 완료본을 통해 변화과정을 추적할 수 있다.

## 5. 1차 대시보드 기능
- 국내 생산·내수·수출 월별 흐름과 연간 흐름
- 글로벌 시장군/국가 필터
- 글로벌 수요(등록·판매) / 생산 / 수출 축 분리
- 결측월 비연결 표시
- 국가별 source, vehicle_scope, note 확인
- 특허 기존기술(ABS·ESC) / 신기술(통합제동·BBW/EMB) 이중축
- 기술 신호 카드
- 질문 해석 MVP 및 해석 주의사항 표시

## 6. 현재 한계
1. 글로벌 국가별 기간이 서로 다르다. 브라질·멕시코·인도는 최신 구간 중심이고 중국은 2023 기준선이 중심이다.
2. 등록·판매·생산·수출은 정의가 달라 글로벌 총시장 하나의 숫자로 합산하지 않았다.
3. 뉴스는 질문 해석의 근거 데이터로 아직 자동 연결하지 않았다.
4. 중국 생산의 2023-09~11은 미확보지만 2023 기준 NULL 25%로 내부 30% 규칙은 통과했다.
5. 향후 월별 증분수집을 위한 통합 실행기는 설계 방향만 확정했고 2차에서 구현한다.

## 7. 향후 과제
**시장 확대:** 성장아시아(인도네시아·태국·베트남 검토), 중동, 중앙아시아/CIS 확대, 아프리카.  
**시계열 보완:** 중국 장기 월별, 브라질·멕시코·인도 과거구간 확장.  
**자동 업데이트:** 국가별 마지막 수집월을 읽고 신규 월만 수집하는 `update_global_market.py` 통합 실행기.  
**뉴스 근거:** 질문 해석 → 관련 뉴스/공식 발표 → 근거문장 → 시장/특허 데이터 연결.  
**품질관리:** source registry, 월별 coverage, 정의 변경 감지, 중복·이상치 자동검사.  
**대시보드:** 국가명 한글화, 비교기간 정규화, 모바일 화면 미세조정, 질문→사전정의 분석명령 연결.

## 8. 다음 과제 재사용 프롬프트
아래 프롬프트는 다음 시장/기술 데이터 프로젝트 시작 시 그대로 복사해 사용할 수 있도록 정리한 것이다.

```text
무료 공개데이터 기반 시장분석 프로젝트를 구축한다.

[기본 원칙]
1. 공식·무료 원자료를 최우선으로 사용한다. 유료자료는 사용하지 말고 존재 여부만 기록한다.
2. 수집 전에 API/CSV/Excel → 공식 HTML 표 → 공식 PDF 순으로 가장 가벼운 접근을 확인한다.
3. 자동수집 실패를 '데이터가 없음'으로 단정하지 말고 URL 구조, JavaScript 버튼, SSL, 파일형식, 접근방식 문제를 분리 진단한다.
4. 대량 크롤링 전에 예상 요청횟수 × timeout을 계산한다. 오래 걸릴 구조면 시작하지 말고 공식 목록/검색 인덱스로 URL을 먼저 좁힌다.
5. PDF는 반복해서 전체 분석하지 않는다. 최초 1회 구조분석 후 필요한 표/페이지를 CSV 등 중간 산출물로 캐시하고 이후 단계는 캐시를 재사용한다.
6. 월별 값과 누계가 같이 있으면 누계로 교차검증한다. 검증 전 숫자는 MASTER에 넣지 않는다.
7. NULL은 0으로 채우지 않는다. 계열별 결측률을 계산하고 기본적으로 30% 초과 계열은 합계/대표선에서 제외한다.
8. 추정값은 근거가 있을 때만 사용하며 ACTUAL과 분리하고 source, estimate_method, note를 반드시 남긴다.
9. 등록, 판매, 생산, 수출 또는 차량범위가 다른 데이터는 임의 합산하지 않는다. 공통 비교축을 만들더라도 원래 metric과 scope를 보존한다.
10. 최신월 국가수가 줄어드는 다국가 합계는 coverage gate를 적용한다. 예: 기준국가의 70% 이상이 있는 월만 합계를 표시한다.
11. 이미 확보한 과거를 매번 재수집하지 않는다. 마지막 수집월 이후 신규 월만 증분 수집한다.
12. 데이터 수집 중 실패한 접근도 삭제하지 말고 '문제→원인→버린 방법→해결 방법→재사용 교훈'으로 기록한다.

[특허/기술 데이터]
- 광범위 키워드 검색 후 바로 집계하지 않는다.
- 제목/초록 필드, IPC/CPC 등 분류코드, STRICT 분류를 조합한다.
- 전체수집 전에 작은 샘플로 PASS/REVIEW 비율을 확인한다.
- 기존기술과 신기술의 건수 스케일이 크게 다르면 차트 축 또는 패널을 분리한다.
- 특허 건수를 시장규모나 시장점유율로 표현하지 않는다.

[대시보드]
- 초기안 → 분석형 개선안 → 최종안 최소 3단계의 변화와 이유를 기록한다.
- 스케일이 다른 데이터를 한 축에 억지로 넣지 않는다.
- 국내/해외, 수요/생산/수출 등 분석 목적에 맞는 구분을 유지한다.
- 결측을 선으로 강제 연결하지 않는다.
- 각 그래프가 답해야 할 질문을 먼저 정의한다.
- 빈 공간은 장식보다 질문 해석, 출처, 주석, 판단 보조에 사용한다.
- AI 질문 기능은 처음부터 자유생성 답변보다 '질문→분석항목/사전정의 명령→근거 데이터' 구조로 시작한다.

[완료 판단]
시장 추가 자체를 목표로 삼지 않는다. 핵심 시장 데이터가 검증되고 대시보드가 의사결정에 사용할 수 있는 상태가 되면 1차를 종료한다. 추가 국가, 장기 시계열, 자동수집, 뉴스연결은 향후과제로 명시한다.
```

## 9. 1차 완료 판단
1차 목표였던 무료 공개데이터 기반 시장·기술 분석 구조, 데이터 품질 원칙, 글로벌 확장 가능 MASTER, 대시보드 MVP를 확보했다. 따라서 **추가 시장 수집은 2차 과제로 이관하고 1차 과제를 완료 상태로 관리**한다.
