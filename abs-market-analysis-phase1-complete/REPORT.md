# ABS Market Intelligence — 1차 시계열 시장·기술 분석 리포트

## 1. 분석 주제 및 목적

본 프로젝트의 1차 목표는 자동차 시장의 생산·내수·수출 시계열을 정리하고, 변동성과 기술 전환 신호를 함께 보면서 **“시장이 어떻게 변하고 있는가?”와 “제동기술은 어느 방향으로 이동하고 있는가?”**를 데이터 기반으로 확인하는 것이다.

단순 그래프 작성이 아니라 다음 순서로 분석하였다.

**자료 수집 → 데이터 정제 → 시계열 연결 → 이동평균·변동성 분석 → 질문 설정 → 관찰(Fact)과 해석(Why) 분리 → 대시보드 탐색**

최종적으로 Streamlit 기반 2화면 대시보드를 구성하여 기간을 바꾸면서 시장동향과 변동분석을 탐색할 수 있도록 하였다.

---

## 2. 분석 질문

1. 국내 자동차 생산·내수·수출은 시간에 따라 어떤 흐름을 보이는가?
2. 특정 시점에 월별 변동성이 확대되거나 흐름이 꺾이는 구간이 있는가?
3. 최근 생산·내수·수출 흐름은 선택한 분석기간에서 어떻게 달라지는가?
4. 글로벌 주요 시장은 동일한 방향으로 움직이는가, 국가별 차이가 있는가?
5. ABS 이후 ESC·통합제동·Brake-by-Wire/EMB로 이어지는 기술 변화 신호를 확인할 수 있는가?
6. 현재 자료만으로 확인 가능한 사실과 추가 근거가 필요한 해석은 무엇인가?

---

## 3. 데이터 설명

### 3.1 국내 시장

국내 자동차 생산·내수·수출 월별 데이터를 중심 시계열로 사용하였다. 장기간 월별 자료를 확보하는 과정에서 원문 PDF와 복구 자료를 함께 점검하였다. 프로젝트 자료에는 2015년 이후 다수의 월별 원문/복구 PDF가 존재하며, 월별 원천자료를 장기간 수집·복구한 흔적이 남아 있다.

주요 지표는 다음과 같다.

- 생산: 자동차 생산 대수
- 내수: 국내 판매/등록 관련 월별 대수
- 수출: 자동차 수출 대수
- 단위: 차량 대수(EA)
- 분석 단위: 월

### 3.2 글로벌 시장

1차에서는 공개·공식자료를 확보할 수 있는 범위에서 국가별 시계열을 추가하였다.

- 중국: CAAM
- 인도: SIAM
- 브라질: ANFAVEA
- 멕시코: 공개 공식통계 기반 생산·판매·수출
- 칠레 등: 확보 가능한 등록계열
- 글로벌 생산 장기계열: 공개 통계자료

국가마다 `판매`, `등록`, `생산`, `수출`의 정의와 vehicle scope가 다르므로 **서로 다른 지표를 하나의 절대수량으로 단순 합산하지 않았다.**

### 3.3 기술동향

기술동향은 자동차 시장 시계열과 별도로 다음 흐름을 관찰하였다.

**ABS → ESC → 통합제동 → Brake-by-Wire / EMB**

제조사·기술기업 공식 공개자료에서 확인 가능한 기술 신호를 별도 데이터로 관리하였다. 특허는 1차 과정에서 수집·분류를 시도했으나 최종 대시보드에서 사용할 연도별 원본 CSV 연결이 완료되지 않은 경우 **임의 건수를 생성하지 않고 미연결 상태를 표시**하도록 하였다.

## 4. 데이터 수집 과정과 해결 방법

이번 과제에서 가장 많은 시간이 들어간 부분은 그래프 작성이 아니라 **서로 다른 기관의 자료를 실제 분석 가능한 월별 시계열로 만드는 작업**이었다.

### 4.1 국내 월별 자료

문제:
- 월별 자료가 단일 CSV가 아니라 PDF·첨부자료 등 여러 형태로 존재
- 과거 문서의 파일명과 실제 내용이 일치하지 않는 경우 확인 필요
- 일부 자료의 누락 또는 복구본 존재

해결:
1. 원본 파일을 가능한 범위에서 보존
2. 월/자료 identity를 교차 확인
3. 자동 추출 결과를 그대로 신뢰하지 않고 검증용 테이블 생성
4. 복구 자료와 원자료를 비교
5. 최종 월별 master에 실제 확인된 값을 연결

### 4.2 브라질 ANFAVEA

문제:
- Carta PDF별로 월별 생산·수출·등록 정보가 분산
- 최신 PDF에 전월 또는 누계 정보가 함께 포함되어 월 구분 필요

해결:
- PDF를 월별로 읽어 공식 Total을 추출
- CURRENT/PREVIOUS 자료를 구분
- 동일 월 중복 여부를 audit 파일로 확인
- NULL 비율을 계산하여 집계 후보 여부를 판단

결과적으로 브라질은 생산·수출·등록의 실제 월별 관측값을 확보하여 중남미 비교축에 포함하였다.

### 4.3 중국 CAAM

문제:
- CAAM 영문 사이트의 HTML 표 구조가 안정적인 자동 파싱에 적합하지 않음
- 공식 사이트 SSL 인증서 만료 문제 발생
- 전체 사이트 크롤링은 속도가 매우 느리고 효율이 낮았음

해결:
1. 처음에는 안전한 자동 파싱 실패 시 master를 변경하지 않음
2. CAAM 공식 도메인에 한정하여 SSL verify 우회
3. 소수 상세 페이지로 구조를 먼저 확인
4. `Total Cars`의 당월 값과 누계 값을 구분
5. 전체 크롤링 대신 필요한 월만 보완하는 방식으로 변경
6. 이미 확보된 값을 빠르게 merge하여 요청 횟수를 최소화

이 과정에서 **“전체를 다시 긁기보다 누락월만 보완한다”**는 방식이 이후 수집 효율을 크게 높였다.

### 4.4 인도 SIAM

문제:
- 상세 월간 Production & Sales 데이터셋 일부가 유료
- 무료 공개자료에서 판매와 생산의 vehicle scope가 동일하지 않음

해결:
- 유료 데이터는 사용하지 않음
- 무료 공식자료 범위만 사용
- `DOMESTIC_SALES = Passenger Vehicles`
- `PRODUCTION = PV + 3W + 2W + Quadricycle`
- 서로 scope가 다르므로 같은 절대규모 축으로 합산·비교하지 않음

### 4.5 결측치 처리 원칙

이번 프로젝트에서 가장 중요한 데이터 처리 원칙 중 하나는 다음과 같다.

> **NULL / 미수집 / 미확인 값은 0이 아니다.**

따라서:
- 없는 월을 0으로 채우지 않음
- 실제 0과 미수집을 구분
- 시각화는 실제 관측값을 사용
- 부분연도를 완결연도처럼 표시하지 않음
- 연도 비교 시 최신연도와 동일기간(YTD) 기준을 사용

초기 대시보드에서 0 대체와 부분연도 표현 때문에 그래프가 왜곡되는 문제가 있었고, 최종 버전에서 이 원칙을 다시 적용하였다.

## 5. 시계열 분석 방법

### 5.1 이동평균

월별 원자료의 단기 등락만으로 방향을 판단하지 않기 위해 **3개월 이동평균**을 사용하였다.

목적:
- 월별 노이즈 완화
- 단기 추세 확인
- 최근 흐름의 방향성 비교

### 5.2 변동성

변동성은 **12개월 rolling 표준편차**를 사용하였다.

초기 구현에서는 실제 값의 표준편차와 변화율 기반 변동성 표현이 혼동되는 문제가 있었으므로, 최종 대시보드에서는 지표명과 계산 의미가 일치하도록 정리하였다.

변동성 값은 “원인”이 아니라 **움직임이 커졌다는 관찰 지표**로 사용한다.

### 5.3 전년동월 및 동일기간 비교

최신연도가 아직 12개월을 채우지 못했을 때 연간 합계처럼 표시하면 비교가 왜곡된다.

따라서:
- 최신 부분연도는 동일 월수의 전년/과거 기간과 비교
- 완결연도와 부분연도를 동일한 연간 합계로 직접 비교하지 않음

## 7. 질문 기반 분석 방식

AI 분석은 숫자만 보고 원인을 확정하지 않도록 다음 구조를 사용하였다.

### 관찰 (Fact)

현재 데이터에서 직접 계산하거나 그래프에서 확인할 수 있는 사실만 기록한다.

예:
- 최근 관측값
- 전년동월 변화
- 이동평균 방향
- 변동성 확대 시점

### 해석 (Why)

가능한 설명은 가설로 구분한다.

예:
- 계절성
- 조업일수
- 수요 변화
- 생산차질
- 국가별 산업환경

외부 근거가 없는 경우 원인으로 단정하지 않는다.

### 사업적 의미 / 다음 확인

현재 시장 시계열과 기술전환 신호를 연결해 추가로 확인해야 할 데이터를 제시한다.

이 구조를 사용함으로써 **AI가 만든 해석과 실제 데이터에서 확인된 사실을 분리**하였다.

## 8. 주요 인사이트

### 인사이트 1 — 시장 규모와 시장 변동은 다른 질문이다

관찰(Fact):
- 생산·내수·수출의 절대 규모와 월별 움직임은 서로 다른 패턴을 보일 수 있다.
- 이동평균과 변동성을 함께 볼 때 단순 월별 값보다 흐름 변화가 명확해진다.

해석(Why):
- 단일 월의 급등락만으로 시장 방향을 판단하기보다 일정 기간의 추세와 변동성을 함께 봐야 한다.

행동(Action):
- 향후 시장점유율 분석에서도 절대 시장규모와 성장/변동 지표를 분리해 관리한다.

### 인사이트 2 — 글로벌 데이터는 ‘같은 숫자’보다 ‘같은 정의’가 중요하다

관찰(Fact):
- 중국·인도·브라질·멕시코 등 국가별 공개자료는 판매/등록/생산/수출 및 차량범위가 서로 다르다.

해석(Why):
- 단순 합산은 큰 숫자를 만들 수 있지만 비교 의미가 약해질 수 있다.

행동(Action):
- 2차 분석에서는 국가별 scope와 정의를 먼저 표준화한 뒤 시장점유율 계산 가능 여부를 판단한다.

### 인사이트 3 — 기술 변화는 자동차 생산량만으로 설명되지 않는다

관찰(Fact):
- 제동기술은 ABS에서 ESC, 통합제동, Brake-by-Wire/EMB 방향으로 확장되는 기술신호가 존재한다.

해석(Why):
- 차량 생산량이 증가하지 않더라도 시스템 구조 변화에 따라 부품의 적용 위치·수량·가치가 달라질 수 있다.

행동(Action):
- 다음 단계에서는 OEM/차종별 제동시스템 장착률과 Coil Ass'y 적용량을 연결해야 한다.

## 9. 결론

1차 과제를 통해 **국내·글로벌 자동차 시장 시계열 수집 및 정제 → 시계열 분석 → 변동성 분석 → 질문 기반 해석 → 기술동향 연결 → 탐색형 대시보드**까지 하나의 흐름을 구현하였다.

이번 결과의 가장 큰 의미는 단순히 그래프를 만든 것이 아니라, 실제 공개자료를 분석 가능한 구조로 만들면서 다음 원칙을 확립한 데 있다.

- 원자료를 보존한다.
- 추정값과 실제값을 구분한다.
- 미수집을 0으로 바꾸지 않는다.
- 서로 다른 scope를 억지로 합치지 않는다.
- 관찰과 해석을 분리한다.
- 자동수집이 어려우면 전체 크롤링보다 필요한 누락구간을 선택적으로 보완한다.

현재 결과는 **시장 방향을 탐색하는 1차 기반**이며, 최종 사업 의사결정에 필요한 시장점유율까지 완성된 것은 아니다.

## 10. 한계점

- 국가별 데이터 기간과 지표 정의가 동일하지 않음
- 일부 국가는 공개자료 범위가 짧음
- 중국 등 일부 공식 사이트는 자동수집 안정성이 낮음
- 인도 상세 월별 데이터 일부는 유료이므로 사용하지 않음
- 특허 연도별 원본 데이터의 최종 대시보드 연결이 미완료
- 뉴스·기업 이벤트와 시장 변동의 인과관계 검증 미완료
- OEM/차종별 ABS·ESC·통합제동·BBW 장착률 미연결
- Coil Ass'y 실제 적용수량과 시장점유율 계산 근거 미완성

따라서 1차 결과의 해석은 **시장·기술 방향을 탐색하는 수준**으로 제한한다.

## 11. 2차 과제

1. 미수집 국가/시장 추가
2. 국가별 데이터 scope 표준화
3. OEM·차종별 생산/판매 연결
4. ABS·ESC·통합제동·BBW/EMB 장착률 조사
5. Coil Ass'y 적용수량 구조 연결
6. 시장점유율 계산
7. 뉴스/산업 이벤트를 시계열 변화시점과 연결하고 출처 근거 표시
8. 관련 기업 주가와 기술·시장 이벤트 비교
9. KIPRIS 특허 원본 데이터 보강 및 기술분류 검증
10. 시장·기술·기업 신호를 통합하여 **“어느 시장/기술에 집중할 것인가?”** 분석

## 12. AI 사용 로그

### 사용 작업

- 데이터 수집 코드 작성 및 수정
- PDF/HTML/CSV 구조 파악
- 데이터 정제 및 병합 로직 작성
- 결측/중복 검증 코드 작성
- 이동평균·변동성 등 시계열 분석 코드 작성
- Streamlit 대시보드 구현
- 질문 기반 Fact/Why 구조 작성
- 리포트 구조화 및 문장 정리

### 사용 이유

- 반복적인 수집·검증 코드 작성 시간 단축
- 기관별 서로 다른 데이터 구조의 처리 대안 탐색
- 오류 발생 시 원인 후보와 수정방법 탐색
- 시각화/대시보드 구현 속도 향상
- 분석 내용을 일관된 형식으로 정리

### 검증 방법

AI가 생성한 결과를 그대로 사용하지 않고 다음 방식으로 검증하였다.

- 공식 원문과 추출값 비교
- 월별 누락률/coverage 확인
- 중복월 확인
- 샘플 페이지 수동 비교
- 실제 관측값과 NULL 구분
- 데이터 scope 확인
- 대시보드 화면에서 그래프 왜곡 여부 확인
- 잘못된 연간 합계/0 대체/변동성 표현 발견 시 계산 로직 수정

AI는 코드와 분석을 보조했으며 **최종 데이터 사용 여부와 해석 판단은 사람이 검토하였다.**

## 13. 대시보드 개선 과정

### 1차 — 기본 시계열 표시

초기 화면은 생산·내수·수출 데이터를 단순 그래프로 표시하는 수준이었다.

문제:
- 데이터가 있어도 활용도가 낮음
- 스케일 때문에 변화가 잘 보이지 않음
- 결측값 표현 문제
- 질문/해석 연결 부족

개선 방향:
- 시장동향과 변동분석을 분리
- 시계열 분석 목적을 화면에 반영

### 2차 — 시장동향 / 변동분석·기술동향 2화면 구조

화면 수를 늘리기보다 두 개의 분석 목적에 집중하였다.

개선:
- 시장동향: 국내/글로벌 시계열
- 변동분석: 이동평균·변동성
- 질문: Fact/Why 구조
- 기술: ABS → ESC → 통합제동 → BBW/EMB

발견된 문제:
- 부분연도 연간 비교
- NULL을 0처럼 보이게 하는 표현
- 고정된 분석기간
- 글로벌 국가별 스케일 차이

### 3차 — 최종 탐색형 대시보드

최종 개선:
- 2화면 구조 유지
- 기간검색 추가
- KPI/시계열/질문분석을 선택기간과 연결
- 동일기간 비교 적용
- 미수집값 0 대체 금지
- 실제 근거 없는 특허값 생성 금지

**개선 원칙:** 기능이나 페이지를 계속 늘리는 것이 아니라, 수집한 데이터를 사용자가 실제로 탐색할 수 있도록 핵심 기능의 연결성을 높였다.

## 14. 다음 프로젝트에서 재사용할 프롬프트

```text
[시계열 시장분석 프로젝트 진행 원칙]

목표:
공개/공식 데이터를 수집해 시장의 장기 흐름, 변동성, 기술변화를 분석하고
최종적으로 사업 의사결정에 사용할 수 있는 탐색형 대시보드와 리포트를 만든다.

1. 데이터 수집 전
- 먼저 분석 질문을 정의한다.
- 기관별 metric, unit, vehicle scope, 기간, update cycle을 표로 만든다.
- 같은 이름의 지표라도 정의가 다르면 별도 계열로 관리한다.
- 유료 데이터는 사용하지 않는다.

2. 수집
- 원본(raw)을 반드시 보존한다.
- 전체 사이트를 무조건 크롤링하지 않는다.
- 샘플 2~5개로 구조를 먼저 확인한다.
- 자동 파싱 신뢰도가 낮으면 master에 바로 넣지 않고 audit/review로 보낸다.
- 과거 데이터가 이미 있으면 누락구간만 보완한다.

3. 결측치
- NULL, 미수집, 미확인은 0이 아니다.
- 임의로 0을 채우지 않는다.
- 실제 0만 0으로 기록한다.
- 부분연도는 완결연도와 동일 방식으로 비교하지 않는다.

4. 검증
- 원문 ↔ 추출값 샘플 검증
- 중복 월 검증
- coverage / missing month 확인
- 단위 검증
- 누계값과 당월값 구분
- metric scope 검증
- 추정값은 ACTUAL과 분리

5. 분석
- 원시 시계열
- 이동평균
- 전년동월 변화
- 동일기간 누적
- rolling 변동성
중 최소 2개 이상을 적용한다.

6. 해석
항상 아래 세 부분을 분리한다.
- Fact: 데이터에서 직접 확인된 사실
- Why: 가능한 원인/가설. 외부근거 없으면 단정 금지
- Action: 사업적으로 다음에 확인할 데이터/행동

7. 대시보드
- 페이지 수를 늘리는 것을 완성도로 착각하지 않는다.
- 핵심 질문 기준으로 최소 화면을 만든다.
- 기간 검색은 시계열 대시보드의 기본 기능으로 넣는다.
- 기간 변경 시 KPI, 그래프, 분석문이 함께 바뀌게 한다.
- 국가별 규모 차이가 큰 계열은 한 축에 억지로 합치지 않는다.

8. 리포트
반드시 포함:
- 분석 주제
- 질문 3개 이상
- 데이터 출처/기간/정의
- 결측/이상치 처리
- 분석방법
- 시각화
- Fact/Why 인사이트
- 결론/한계
- AI 사용 로그
- 향후과제
- 수집 중 발생한 문제와 해결 노하우

9. 완료 기준
화면이 예쁜지만 확인하지 않는다.
'수집한 데이터가 실제 분석 기능에 연결되어 있는가?'를 마지막으로 검증한다.
```
