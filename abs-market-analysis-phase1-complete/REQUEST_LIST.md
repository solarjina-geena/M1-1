# REQUEST_LIST — ABS Market Intelligence

## 1. 프로젝트 목적

- 단순 과제용 그래프가 아니라 실제로 보고 싶은 자동차 시장 데이터를 구축한다.
- 시장분석과 기술분석을 통해 향후 가야 할 방향을 판단할 기반을 만든다.
- 장기적으로 시장점유율과 ABS Coil Ass'y의 사업기회를 확인한다.

## 2. 사용자가 요청한 핵심 요구사항

1. 시계열 데이터 최소 100개 이상을 확보한다.
2. 국내 자동차 생산·내수·수출 데이터를 장기간 연결한다.
3. 글로벌 주요시장 데이터를 추가한다.
4. 데이터 수집 출처와 기간을 기록한다.
5. 결측치/이상치 처리 기준을 설명할 수 있어야 한다.
6. NULL/미수집값을 0으로 넣지 않는다.
7. 있는 데이터만 이어서 시계열을 표현한다.
8. 부분연도를 연간 전체값처럼 표시하지 않는다.
9. 이동평균·변화율·변동성 등 시계열 분석을 적용한다.
10. 변동분석은 텍스트가 아니라 그래프로 표현한다.
11. 분석 질문을 3개 이상 둔다.
12. 질문에 대한 해석을 대시보드에서 확인할 수 있게 한다.
13. 관찰(Fact)과 해석(Why)을 분리한다.
14. 국내/글로벌 시장을 탐색할 수 있게 한다.
15. 글로벌 데이터는 국가별 정의/스케일 차이를 고려한다.
16. 기술동향 화면은 ABS → ESC → 통합제동 → BBW/EMB 흐름을 유지한다.
17. 특허 데이터는 실제 확보값만 사용한다.
18. 근거가 없는 숫자를 만들어 넣지 않는다.
19. 기술신호는 제조사/공식자료 근거를 사용한다.
20. 대시보드는 화면 수를 늘리지 않고 2장으로 수준 있게 구성한다.
21. 1장: 시장동향.
22. 2장: 변동성 + 질문분석 + 기술동향.
23. 대시보드에 기간검색을 넣는다.
24. 기간 변경이 그래프뿐 아니라 KPI와 질문분석에도 연결되게 한다.
25. 대시보드 디자인은 정보가 많아도 복잡하지 않고 전문적으로 보이게 한다.
26. 1차 과제는 현재 확보 데이터로 마무리한다.
27. 시장점유율 등 미완료 목표는 2차 과제로 명확히 남긴다.
28. 미수집 시장을 2차에서 추가한다.
29. 뉴스 조사와 출처 근거를 2차에 포함한다.
30. 관련 기업 주가 근거/이벤트 분석을 2차에 포함한다.
31. 특허 원본 데이터 보강을 2차에 포함한다.
32. 데이터 수집이 어려웠던 이유와 해결과정을 REPORT에 남긴다.
33. 대시보드 변화과정을 약 3단계로 정리한다.
34. 각 단계에서 왜 개선했는지 코멘트를 남긴다.
35. 다음 과제에서 재사용할 수 있도록 수집·검증·분석 노하우를 프롬프트로 정리한다.
36. AI 사용 로그를 REPORT에 포함한다.
37. GitHub 저장소에 코드·리포트·실행방법·가능한 데이터/수집방법을 남긴다.

## 3. 1차 완료 범위

- 국내 시계열 구축
- 글로벌 주요시장 일부 구축
- 이동평균/변동성
- 질문 기반 Fact/Why 분석
- 기술동향
- Streamlit 2화면 대시보드
- 기간검색
- REPORT / README / REQUEST_LIST 정리

- Coil Ass'y 적용량
- 뉴스 근거
- 주식/기업 이벤트
