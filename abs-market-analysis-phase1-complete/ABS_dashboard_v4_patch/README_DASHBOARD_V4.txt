ABS Dashboard V4
================
목표: 화면 2장만 사용
1) 시장동향: 국내 시계열 + 동일기간 연간비교 + 글로벌 시장
2) 변동분석·기술동향: 변동성 + 질문분석 + 특허 + 공식 기술신호

중요 규칙
- NULL/미수집 월을 0으로 대체하지 않음
- 최신 부분연도는 과거 연도와 동일기간 누적으로 비교
- Fact와 Why 분리
- 특허 CSV가 없으면 임의 숫자를 만들지 않고 '미연결' 표시

설치
1. ZIP을 프로젝트 루트에 압축 해제
2. PowerShell에서 프로젝트 루트로 이동
3. python .\apply_dashboard_v4.py
4. streamlit run app.py
